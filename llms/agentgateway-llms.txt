# agentgateway | Agent Connectivity Solved

> Agentgateway is an open source HTTP and gRPC proxy and gateway that unifies everyday API traffic with LLM, MCP, and A2A workloads in one data plane — connecting, securing, and observing agent-to-agent, agent-to-tool, and agent-to-LLM communication across any agent framework and environment.
